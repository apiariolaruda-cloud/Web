APIARIO LA RUDA - KEEPALIVE AUTOMATICO DE SUPABASE
===================================================

OBJETIVO
Evitar que el proyecto Free quede sin actividad durante muchos días cuando no
haya pedidos ni consultas reales. El mecanismo hace solamente una lectura mínima
de la base. No crea pedidos, no cambia estados y no expone datos de clientes.

IMPORTANTE
Supabase indica que los proyectos Free con baja actividad pueden pausarse y que
unas pocas solicitudes de usuario a la base por día suelen ser suficientes para
no ser candidatos a pausa. Esto ayuda mucho, pero la garantía absoluta de que un
proyecto nunca sea pausado por inactividad solamente existe en un plan pago.

PARTE 1 - SUPABASE
1. Ejecutar el archivo supabase_setup.sql COMPLETO en Supabase > SQL Editor.
   El archivo ya incluye la función:

       public.la_ruda_keepalive()

2. La función hace una lectura mínima de public.orders y responde algo similar a:

       {"ok":true,"checked_at":"2026-08-25T..."}

3. No devuelve nombres, teléfonos, artículos ni ningún otro dato del pedido.

PARTE 2 - CREAR LA CONSULTA AUTOMATICA EN CRON-JOB.ORG
1. Crear una cuenta gratis en https://cron-job.org
2. Elegir CREATE CRONJOB.
3. Título:

       Apiario La Ruda - Supabase Keepalive

4. URL:

       TU_SUPABASE_URL/rest/v1/rpc/la_ruda_keepalive

   Ejemplo:
       https://abcdefghijk.supabase.co/rest/v1/rpc/la_ruda_keepalive

5. Método HTTP: GET

6. Frecuencia recomendada: CADA 6 HORAS (4 veces por día).
   No hace falta ejecutarlo cada pocos minutos.

7. Agregar estos encabezados personalizados (Custom Headers):

       apikey: TU_SUPABASE_ANON_KEY
       Authorization: Bearer TU_SUPABASE_ANON_KEY
       Accept: application/json

   La anon key es la misma clave pública usada por la web. NO usar service_role.

8. Activar notificación por fallo si cron-job.org ofrece esa opción.

9. Ejecutar una prueba manual (Test / Run now).

RESULTADO CORRECTO
- HTTP Status: 200
- Respuesta con "ok": true

Si devuelve 401/403:
- revisar la anon key;
- revisar que se haya ejecutado el supabase_setup.sql actualizado;
- revisar que la URL termine exactamente en /rest/v1/rpc/la_ruda_keepalive

SEGURIDAD
- NO colocar la contraseña de administrador en cron-job.org.
- NO colocar la service_role key.
- Solo se usa la anon/public key, que ya es una clave destinada a clientes
  públicos y sigue protegida por las reglas de seguridad de Supabase.

COMPROBACION
Cron-job.org permite ver el historial de ejecuciones. Si aparecen ejecuciones
HTTP 200 cada 6 horas, el keepalive está funcionando aunque la PC local esté
apagada.
